Neel Soni - Portfolio

A simple, responsive personal portfolio website. It has an About section, my skills, two small projects and a contact form. It works on both mobile and laptop screens and has a dark mode button.

Portfolio screenshot

Technologies Used
HTML5
CSS3 (Flexbox, Grid, media queries)
JavaScript (menu toggle, dark mode, form validation)
Git and GitHub
Features
Mobile menu that opens and closes
Dark mode / light mode button
Contact form that checks the fields before sending
